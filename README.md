# 📊 Customer Retention & Churn Analysis

## 🔍 About the Project
This project analyzes telecom customer data to identify churn patterns, 
key retention drivers, and customer lifetime trends.
Completed as part of FutureInterns Data Science & Analytics Internship - Task 2.

## 🛠️ Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Dataset
- Source: Telco Customer Churn Dataset (Kaggle)
- Records: 7,032 rows and 21 columns

## 🔎 Analysis Performed
- Overall Churn Rate Analysis
- Customer Segment Analysis (Gender, Senior Citizen, Partner)
- Contract Type vs Churn Analysis
- Monthly Charges vs Churn Analysis
- Tenure vs Churn Analysis

## 💡 Key Insights
- Analyzed 7,032 customer records with overall churn rate of 26.58%
- Month-to-month customers churn at 42.7% — 15x more than 2 year contracts!
- Senior citizens churn at 41% vs 23% for non-seniors
- Churned customers paid average $80/month vs $65 for retained customers
- 60% of churning happens within first 12 months!
